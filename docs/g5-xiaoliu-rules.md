# G5 小六壬：死六神、天地人三盘与对照样例

本版按道传小六壬整理：邵一尘《道家小六壬》的六神五行与三才框架，以及姒玄《道传小六壬（喂饭篇）》的天地人取象。计算、六位资料、三才解读都在 `src/xiaoliu/`，无需模型、网络或随机数。AI 只解释已经冻结的本课，不更改起课结果。

## 排宫：死六神固定不转

六神取**死六神**，固定对应六宫，不随时辰转动：

| 六宫 | 五行 | 死六神 | 主要象意 |
|---|---|---|---|
| 大安 | 木 | 青龙 | 稳定、守成、贵人、静而不动 |
| 留连 | 土（四方土） | 腾蛇 | 拖延、反复、纠缠、暗昧 |
| 速喜 | 火 | 朱雀 | 消息、文书、快速、口舌 |
| 赤口 | 金 | 白虎 | 分歧、竞争、伤损、官非 |
| 小吉 | 水 | 玄武 | 协商、小成、暗昧、人情 |
| 空亡 | 土（中央土） | 勾陈 | 缺失、未定、牵连、停滞 |

这张表是本版与网传“留连水·玄武、小吉木·六合”版本的关键差异。道传以**留连为四方土、小吉为玄武水**，并取腾蛇配留连、勾陈配空亡；不再使用六合配小吉。活六神是另一套按时辰起转的辅助取象法，本版明确不混用：`src/xiaoliu/reading.ts` 只做固定排宫。

## 天地人三盘

三宫不是三个并列的标签，而是一条推进线：

| 盘 | 宫 | 所主 |
|---|---|---|
| 天盘 | 月宫 | 起因、天时、环境、对方、时间 |
| 地盘 | 日宫 | 经过、地利、条件、现状、地点 |
| 人盘 | 时宫 | 结果、人和、卦主、行动 |

- 月宫为天盘，先定事情的来处与外部条件。
- 日宫为地盘，承接天盘，显示过程里的助力、阻力与拖延。
- 时宫为人盘，是本次落宫，也是卦主的位置与可行动之处。
- 三宫之间按五行生克读出“助、制、争、孤”；生克不直接改写落宫吉凶，落宫仍是本次结果。

固定约定：

| 项目 | 本版约定 |
|---|---|
| 月数 | 所选时区的农历月份 1—12，不用节气月或公历月 |
| 闰月 | 同名月份取同一个数，例如闰二月仍取 2；不额外进一宫 |
| 日数 | 农历初一取 1、三十取 30 |
| 时数 | 子至亥取 1—12；子时为 23:00—00:59，其余每两小时一位 |
| 日界 | 当地民用零点换日；23:00 只换时辰，不提前换日期 |
| 计数 | 每段都含起点计 1；月宫起初一、日宫起子时 |
| 结果 | 同时保存月、日、时三宫，以时宫为最终落宫 |
| 时间范围 | 沿用已有 ICU 农历的 1900—2100 年验证边界；不存在的当地时间拒绝 |

用零下标表示六宫时，月宫 `(month - 1) mod 6`，日宫 `(monthIndex + day - 1) mod 6`，时宫 `(dayIndex + hourNumber - 1) mod 6`。余零就是大安，界面显示“天宫 · 月宫”“地宫 · 日宫”“人宫 · 时宫 · 落宫”。过程文字保留每段起点和计数，用户能逐步人工核对。

## 三才解读

`composeXiaoliuReading` 先按问题关键词粗分主题（感情、事业、财运、健康、出行、寻物、学业、人际、决策；没有命中则为综合），再按天→地→人的顺序生成：

- `heaven`：天盘的宫位、死六神、五行与起因/环境取象。
- `earth`：地盘的承接、条件与过程，并写明天盘对地盘的生态或克态。
- `human`：人盘的落点、卦主位置与行动，并写明地盘对人盘的生态或克态。
- `relations`：天→地、地→人的生克链，以及整体是“得生、受克、输血、比和”中的哪一种。
- `advice`：以人盘为主的行动建议，并附主题相关的边界提醒（如健康以医生诊断为准）。
- `summary`：用“快起/稳承/缓落”等节奏词概括三才走势。

主题词只调整观察角度，不改变落宫、六神、五行和生克方向；解读不输出确定应期、疾病诊断或必然吉凶。

## 独立人工对照

| 公历当地时间 / Asia/Shanghai | 日期来源或规则来源 | 预期月宫 → 日宫 → 时宫 |
|---|---|---|
| 2024-04-13 08:00，三月初五辰时 | 天文台四月原页确认农历；原书直接给出本例 | 速喜 → 大安 → 小吉 |
| 2024-02-10 00:00，正月初一子时 | 天文台二月原页确认初一；三段含起点各只数一步 | 大安 → 大安 → 大安 |
| 2024-02-09 23:00，十二月三十子时 | 天文台二月原页确认三十；本项目零点换日 | 空亡 → 小吉 → 小吉 |
| 2024-04-08 00:00，二月三十子时 | 天文台四月原页确认三十 | 留连 → 大安 → 大安 |
| 2024-04-09 00:00，三月初一子时 | 天文台四月原页确认初一 | 速喜 → 速喜 → 速喜 |
| 2023-03-22 00:00，闰二月初一子时 | 既有 ICU 闰月回归样例；按明确闰月约定计数 | 留连 → 留连 → 留连 |

宫位顺数沿用《玉匣记》三月初五辰时例作为人工对照；六神、五行与三才解读取道传，不取该篇的网传配属。

例如原书例月从大安数到三月为速喜，速喜起初一依次为速喜、赤口、小吉、空亡、大安，随后大安起子时数到辰时为小吉。预期值来自原文和手算，不由 `calculateXiaoliu` 生成。

按本版死六神，2024-04-13 08:00 的三宫为：

- 天盘速喜（火·朱雀）→ 地盘大安（木·青龙）→ 人盘小吉（水·玄武）。
- 地木生天火：地盘在给起因添力。
- 人水生地木：卦主的动作在支撑局面，但也会消耗自己。
- 整体是“快起、稳承、缓落”，适合先做一个小动作，不宜一次压满期待。

## 接口与验证

`calculateXiaoliu({ question, environment: CastEnvironment })` 返回递归冻结的 `XiaoliuResult`，包括 `input`、`lunar`、`monthPalace`、`dayPalace`、`hourPalace`、`name`、`element`、`meaning`、`reading`、`steps`、`conventions`。不保留调用方可变对象。空白问题、超 4000 字符、无效时间与不支持年份拒绝。

`XIAOLIU_PALACES` 导出六宫的编号、名称、五行、死六神、关键词和原创释义；`XiaoliuReading` 导出三才解读字段。`tests/xiaoliu.test.ts` 覆盖原书例、十二时辰两次循环、子初/零点、月末/初一、闰月、跨时区、深度冻结、死六神排宫、三才生克链、主题分类和非法输入。此证据支持本地规则正确性；模型解释质量与桌面交互由集成验收另行记录。
